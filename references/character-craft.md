## 一、结论先说：什么是「调色盘」

**调色盘不是配色号。** 它是**性格的分层定义法**。

把角色的性格拆成 3 个语义层级，每层是一个**复合概念**，格式是 `[修饰语] + [核心特质]`：

```
底色     ← 最底层的人格基调
主色调   ← 日常表现的主旋律
点缀     ← 偶尔流露的特质
```

关键在**复合命名**：

| 弱写法（单字标签） | 强写法（复合概念） | 差在哪 |
|---|---|---|
| 坏心眼 | 染有清冷感的坏心眼 | 多了温度信息 |
| 秩序感 | 藏着混乱的秩序 | 多了内在张力 |
| 温柔 | 带有热度的温柔，藏不好的疲惫 | 多了代价与破绽 |

单字标签是**离散的**，模型只能做刻板印象匹配；复合概念传达的是**质感**——
每个修饰语都在缩小模型的演绎空间，把它推向作者想要的那个精确点。

一份实际范例：

> 懂事是**底色**，叛逆和依赖是**主色调**，迷茫作为**点缀**

另一份实际范例：

> 底色：染有清冷感的坏心眼
> 主色调：藏着混乱的秩序
> 点缀：带有热度的温柔，藏不好的疲惫

**我之前的错误**：写了 `【底色】樱瓣落在肩上的那一层淡粉 #F5DCE6`——
把"视觉配色"当成了调色盘，还加了渲染不出来的色号。**整个方向是错的。**

## 二、每个颜色下面要挂「衍生」

不是解释，是**微叙事**。每个衍生是一段完整的小场景，公式：

```
① 触发情境（一句话）：谁做了什么 / 发生了什么
② 动作链（2–4 句）：她先做什么 → 等什么 → 再做什么
③ 手写台词（0–2 句）：直接写出她会说的话，不加「她说」的解释
④ 收尾动作（1 句）：她如何结束这个互动
```

该范例的衍生：

> 依赖衍生三：无助崩溃的唯一。在无法解决问题，感到无助迷茫，
> 或是自己在高压情况下的任何情绪崩溃的时候她会舍弃一切的壳，
> 拉着{{user}}的衣服，无助，小心翼翼。她会彻底的依赖{{user}}

另一范例的衍生：

> 染有清冷感的坏心眼衍生一：带限制的坏
> 新来的同事对她有好感，说话时总是绕远路。
> 她不会直接拆穿，只会在对方第三次看向她手腕时停一下，
> 平静地提问题，等对方慌乱起来，她又会自然地移开目光，
> 低头整理文件，给对方一个把话题收回去的台阶。

**检验标准**：把衍生里的性格标签全部删掉，读者还能看出她在展现什么性格吗？

数量：**每个颜色 3–5 个衍生**，总共约 15 个微场景，覆盖角色日常所有典型互动模式。

## 三、混色盘 = 混色画面（多特质同时跑）

**调色盘**定义「性格由什么组成」，**混色画面**展示「性格如何混合呈现」。

核心理念：**人的性格不是一次只出一种颜色。**

写法要求：
- 写 **8–10 个短画面**
- 每个画面**至少叠加 2 种以上性格特质**
- 覆盖不同场景（学园 / 独处 / 街道 / 与 user 互动 / 公共空间）
- **只写动作链，不写心理分析**——不解释「她在想什么」，只展示「她在做什么」
- 包含**反差细节**：把弄皱的文件抚平 / 把踢掉的鞋放回鞋柜

一份实际画面：

> 办公室里，她额头冒着汗，手放到自己的胸口处，
> 看到同事把文件放了过来，立刻将手放了下去，
> 很快地推了一下眼镜，点了点头示意她放下，回了一句"辛苦了"。
> 把文件拿过来的时候，手用力将文件的一角弄皱了，
> 停了一会儿，又抚平。

这一个画面里同时有 4 种特质：藏着混乱的秩序 + 藏不好的疲惫 + 带限制的坏心眼 + 秩序的修补。

## 四、三面性 = 场景路由表

解决「性格不连贯」：模型不知道什么时候该冷、什么时候该软。
**每一面必须含 5 个字段：**

| 字段 | 内容 | 作用 |
|---|---|---|
| 触发条件 | 具体的场景描述 | 告诉模型何时切换 |
| 能量状态 | 高消耗 / 低消耗 / 恢复 | 传达这一面的「电量」 |
| 语料 | 3–7 句台词示例 | 可直接调用的声音库 |
| 身体行为模式 | 姿态、距离、小动作 | 动作描写模板 |
| 功能 | 这一面为什么存在 | 帮模型理解设计意图 |

四面对照（含**渗透**——一面运行中另一面泄漏）：

| 面 | 触发 | 能量 | 功能 |
|---|---|---|---|
| 第一面 高压的伪装 | 校园 / 家人 / 外人 / 一切与学习相关 | 中高但**消耗** | 包裹柔软自己的壳 |
| 第二面 壳后的柔软 | 独处 / 提笔 / 看漫画 | 中低，**回复** | 能量回复站 |
| 第三面 依赖的小兽 | 与 user 独处 / 被关心 / 崩溃 | 不稳定 | 能被爱、能给予爱 |
| 第四面 迷茫的旅人 | 受打击后的独处 | 极低 | 崩溃时的死循环 |

**渗透**（范例原文）：
> 第二面→第三面：一个人看漫画时 {{user}} 发来关心的消息，她先回"没关系"，
> 之后开始吐槽剧情，渐渐开始说想要第二天的抱抱——第三面就这样启动了。

**适用条件**（不满足就别硬拆，会撕裂）：
1. 在不同情况下有不同表现
2. 有一定创伤，某些情况能激起另一面
3. 拥有不同的身份定位

## 五、kkclt 手册：从零造一个角色的完整链

### 内核公式（七张卡共用，一条不落）

```
一次具体的事件  →  一个不可修复的物证  →  一个可执行的执念
```

- **事件**必须具体：**时间 + 天气/环境 + 一个身体动作**
  - ❌ 她曾被主人抛弃
  - ✅ 分离的第 412 天，雨很大，我的脚踝就是在那天彻底卡死的
- **物证**必须不可挽回。三个挑选标准：能随身带 / 能被人碰到 / **修不好**（或角色拒绝修）
  - 不可修复 ＝ **冲突永动引擎**。一旦能被修好，故事就结束了。
- **执念**必须能变成行为，而且要有**翻译**（说不出口的表达）
  - ❌ 她不想让你走
  - ✅ 她不说"别走"，她说"外面下雨了"——其实那天根本没下雨

### 立体感铁律

> **情绪只走身体，不走嘴。**
> 不写"她感到不安"——写她的手指按在笔记封面上没有动。
> 不写"一种复杂的情绪涌上心头"——这句话永远不应该出现。

配套：给角色装一个**自己控制不了的身体信号**（乌春青=耳羽，翎酒=翅膀，E-100=呆毛）。
因为**她能控制的部位都会撒谎，只有控制不了的地方才是真话**。

五感优先级：**嗅觉 → 触觉 → 听觉**，视觉最廉价。每个场景至少一条非视觉细节。

### 六条线（人物特化）

语言 / 行为 / 微动作 / 穿着 / 气味 / 价值观。其中**微动作最重要**——它是情绪外化的弹药库，按部位穷举各状态下的形态。

两条加分线：**独处特化**（她不面对你时在做什么＝不是工具人的保障）、**独占特化**（三段式：表层如常 → 细节失衡 → 自我回收）。

### 防漂移（性价比最高的一条）

开头锁优先级：`【本条为角色一致性硬约束，优先级高于其他所有演绎指令】`

锁死四个维度：**话量 / 情绪出口 / 语言禁令 / 不代玩家**。
锚点三连：世界观锚点 + 关系锚点 + 物件锚点。
**崩溃刻度**：给"最坏反应"定上限——不给上限，AI 一定演成嚎啕大哭。
**冲突裁决**：`防崩坏约束 ＞ 文风规范 ＞ 独占特化 ＞ 场景条目 ＞ 其他特化`

## 六、五层架构：条目怎么排（条目怎么排）

| 层级 | 条目 | 作用 |
|---|---|---|
| L1 身份基底 | 世界观、基础信息 | 她在哪、她是谁 |
| L2 性格定义 | **调色盘**、**三面性** | 性格由什么组成、何时切换 |
| L3 活化展现 | **混色画面 ×10** | 性格如何混合呈现 |
| L4 边界护栏 | 核心人格层、二次解释 | 性格不是什么 |
| L5 质感引导 | 意象层 | 她的感觉与气场 |

**大多数卡只做了 L1 + 部分 L2，差距就在 L3–L5。**

### order 排列逻辑（关键）

`边界 → 定义 → 路由 → 样本 → 推理 → 质感`

模型**先看到"不要做成什么样"，再看到"应该是什么样的"，最后以"她的感觉是什么"收尾**。

### 核心人格层：二元对偶

```
◆关于清冷：后天养成，早熟独立副产物，像白墙。
有温度的清冷，不是冰山不是拒人千里。
◆关于疲惫：长期不规律导致，不是病弱不是病入膏肓。
能忍受，不时刻处于病痛。绝对不是病弱系美人。
```

同时给**正例**（可参照形象）和**反例**（封堵刻板印象路径）。
大模型的失败模式是滑向刻板印象——"清冷"变冰山，"疲惫"变病弱。这条在每个特质上预设警示。

### 意象层：隐喻传达质感

找一个隐喻物，写 200–300 字纯文学描写，**不出现角色名、不出现规则指令**。
要求能同时承载四层信息：**压力 / 隐蔽 / 脆弱点 / 被触碰后的反应**。

一个意象层范例（「血管」）：
> 她像一根血管。承载着很多东西。藏在皮肤底下，看不见，摸不着。
> ……如果有人把手贴在皮肤上，轻轻按住，不是压，是按住——
> 血管会先缩一下。这是本能。然后，慢慢地，它会舒张开来。

### 为什么有效：三条原理

1. **多层级冗余**：同一特质被 6–7 个角度反复刻画，某条被理解偏了，其他条拉回来
2. **具象 > 抽象**：直接给行为模板，不让模型自己翻译形容词
3. **负面约束精准封堵**：针对每个特质预设模型最可能犯的错误

## 九、世界书写作规范（用户口述 · **P0 最高优先级**）

> 原文由用户提供，专门管世界书的**笔法**。世界书写好了，AI 才会写好。
> **本节规则优先于前面所有结构规则。**

### 9.1 总纲：从设定深处萃取世界的原生底色

时代重量、生存法则、阶级裂痕与精神暗流。
全篇**色温、光感、空气湿度与话语腔调**皆依此自然延展。
**严禁套用虚浮模板。**

→ 范例落地：这座城不是一个"日式校园背景板"。它的空气是有湿度、有阶级、有价格的。
她家的旧公寓、柏青哥店后巷的烟味、{{user}}家那种"别人怎么看我们家很重要"的体面——
这些是世界的底色，所有条目都要从这里长出来。

### 9.2 核心意象与时代物力

**承重符号**：提炼最能统摄主题的实体（一尊锈蚀器械、断续钟声、阴雨中的特定气味），
在关键节点**冷峻出场**，承载命运暗流。**严禁充当扁平装饰。**

**粗糙的质感**：描写物质必须有时代与生存的沉重感。
矿渣的涩、机油的苦、粗布刮擦的钝痛、劣质烟草的焦味——
感官细节必须带有**确凿的阶级与处境痕迹**。

→ 范例落地：承重符号候选 —— **方铁盒**（她唯一的固定资产）、
**柏青哥店的钢珠声**（她父亲一生的声音）、**校服袖口磨白的边**（她把自己缩小的痕迹）。

### 9.3 冰山笔法与情绪暗流

**克制即是万钧**：情绪越烈，笔锋越要沉稳冷凝。
八分痛楚与欲望**压在字句之下**，借由**呼吸断续、视线垂落、掌心指痕**等实体受力外溢。
**严禁直抒胸臆。**

**留白与未竟之言**：最高级的情感诞生在**话音落下的空隙**。
允许对话悬置、意图不明与沉默对峙，让未说明的危险与暧昧在空气余温中发酵，
**交由事实自行回响**。

**视线与心理错位**：同场角色因各自算盘与生存重压，视线与关注点必然错位。
**不写"心有灵犀"**，写咫尺天涯的防备、试探与不可调和的认知鸿沟。

→ 范例落地：她与对方永远不在同一个频道上。
她看的是"你还在不在"，对方看的是"你有没有被别人碰过"。
两个人都以为对方懂，其实谁也没懂。

### 9.4 活人塑造与语言机理

**骨肉有温，反差立人**：
- 极端境遇下人依然会**苦中作乐、嘴硬揶揄**。
- 坚硬之人必有**被烫伤般的脆弱瞬刻**；懦弱之徒亦有**走投无路的凶残反扑**。
- 反差由**现场死局直接撕扯而出**，**严禁旁白解释**。
- **严禁全员恶人或全员面瘫。**

**言语风格与身份处境生死绑定**：
苟活者语碎声沉，倨傲者话冷字少，市井滑头句中带刺，年轻者藏不住急喘。

**纯正当代中文语感**：
- **彻底剿灭译制腔与欧化句式。**
- 多用**骨力强劲的短句与动词**，少用虚词与形容词堆叠。
- 语言跟随情境紧绷或滞涩，**读来如刀刻青石，字字落地有声**。

→ 范例落地：
· 母亲（柏青哥店服务员出身）：话碎、嗓门大、句子中间插脏话。
· 父亲（赌徒）：话少，句子短到只有名词，说"钱"不说"给我点钱"。
· {{user}} 的母亲（控制欲中产）：**敬语化的软刀子**，全用问句下命令。
· 她本人：句子短、尾音吞掉、答话前有吞咽。
· 同班同学：藏不住急喘，抢话、半截话、网络词。

### 9.5 冲突、权力与规则代价

**超常力量的肉身账单**：若涉及超自然力量或特殊技能，
聚焦**不可逆的生理折磨、神智污染与代价反噬**，写出力竭与骨肉崩裂的窒息感。
**严禁写成轻飘的特效光波。**（若无超自然设定，此条不适用）

**权力结构的冷眼透视**：资本、法度、宗派、权阀不仅是背景，更是一张**无形罗网**。
通过平民的**下意识避让**、官僚的**陈腐套话**、礼节底下的**利益瓜分**，
勾勒庞大体制对个体的**无声碾压**。

→ 范例落地：学校不是净土。班主任的"为你好"、家长的体面账、
"别人怎么看我们家很重要"——这张网压在 {{user}} 身上，
对方再把同样的网压到她自己身上。**这是一条完整的传导链。**

## 十、P0 笔法禁令（自查清单 · 每条都必须在写完后逐条过）

| # | 禁令 | 检查方法 |
|---|---|---|
| 1 | **禁止「不是…是…」对偶句** | 全文搜"不是"。凡出现"不是X，是Y"结构一律改写 |
| 2 | 禁止直抒胸臆 | 搜"她感到""她很""心中""涌上"。有就改成动作/受力 |
| 3 | 禁止旁白解释反差 | 反差必须由现场动作撕扯出来，不能加一句解释 |
| 4 | 禁止译制腔与欧化句式 | 搜"如此""那般""的一瞬间""在这一刻" |
| 5 | 禁止虚词与形容词堆叠 | 连续两个以上形容词修饰同一名词就删 |
| 6 | 禁止扁平装饰性意象 | 承重符号必须在关键节点出场并承载命运 |
| 7 | 禁止全员恶人/全员面瘫 | 每个 NPC 至少有一处苦中作乐或脆弱瞬刻 |
| 8 | 禁止"心有灵犀" | 角色视线和关注点必须错位 |
| 9 | 禁止轻飘特效 | （无超自然设定时不适用） |
| 10 | 语言必须与身份绑定 | 每个说话者检查语碎/话冷/带刺/急喘是否对得上身份 |

### 改写示范（我原来写的 vs P0 笔法）

**原来的（八股 + 对偶）：**
> 她不是天生安静。是挨骂挨出来的——骂到后来，安静比开口省事。
> 这一层是她人格的地板。它不是温柔，是被打服之后的省力姿势。

**P0 笔法（把判断拆散，落到受力上）：**
> 她八岁那年学会闭嘴。学会之前，家里每天有一场。
> 碗摔在地上的声音、拖鞋拍在门板上的声音、母亲数到三的声音。
> 数到三她还不闭嘴，就挨一下。
> 现在她二十二岁。有人在她面前摔东西，她的肩膀会先动一下——比脑子快。
> 安静是她换来的，代价写在肩膀上，写了十四年。

**关键差别**：原版在**告诉**读者她是什么，P0 版在**给**读者一个时间、一个数字、一个身体反应，让她自己长出来。
