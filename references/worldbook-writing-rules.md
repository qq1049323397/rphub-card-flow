# 世界书写法 · 禁句式

**优先级：P0。** 这一页管**落笔的句法**，不管结构、不管字段。
条目内容写得再对，句式踩了这里，就是重写。

来源：用户口述规范（2026-09-21）。**不增补、不引申** —— 只列用户点名的这几条。

> **2026-09-30 补充**：新增第九节「内容组织」。前面八节管**句法**（怎么造句），
> 第九节管**内容**（一条该写什么、写到多满）。两者互不替代，都要过。

## 禁句式

### 1. 禁「不是A而是B」及一切变体

包括：`不是…而是` / `并非…而是` / `与其说…不如说` / `不是…是`。

**要表达 B 就直接陈述 B。** 删掉前半句（A）和那个纠正词，B 自己站得住。

对比只能用在**两件并存的事实**之间，且只准用 `但` / `不过` / `只是` 承接 ——
不是用来制造"先否定再纠正"的戏剧感。

```text
✗ 她不是天生安静。是挨骂挨出来的。
✓ 她八岁那年学会闭嘴。

✗ 与其说她冷淡，不如说她怕。
✓ 有人在她面前摔东西，她的肩膀先动一下。
```

### 2. 禁八股连接词

`首先` `其次` `由此可见` `与此同时` `然而` `因此` `综上`

段落之间靠**事件本身**接续，不靠连接词粘。

### 3. 禁翻译腔插入语

`老实说` `不得不承认` `轻轻地` `缓缓地` `不由自主地`

这类词是在替读者标注语气，把叙述者推到台前。删掉，让动作自己说话。

### 4. 禁破折号（**只管正文散文，结构性标记除外**）

**这条禁令的对象是 AI 写出来的正文句子**，不是世界书的排版符号。
世界书要用破折号做**标记、引用、列表引导**，这是合法结构，不受此限。

语意断裂用**句号、逗号，或生理停顿**（呼吸、动作的停顿）承接。

**受禁令管束（必须改写）**：

- 条目里**连着句子**的破折号 —— 也就是"用来代替逗号/句号做语气转折"的那种
- **示范句、例句**里的破折号 —— 这类最要命，AI 照着模仿语感，等于教它违规
- 章标以外的任何行内破折号

```text
✗ 这些话都是同一个意思——她还在，她还不想走。
✓ 这些话都是同一个意思。她还在，她还不想走。

✗ 她说过一次——十岁那年躲进厕所反锁。
✓ 她说过一次。十岁那年躲进厕所反锁。

✗ （示范句）像一只被光照到的兔子——不跑，也不动。
✓ （示范句）像一只被光照到的兔子。不跑，也不动。
```

**不受禁令管束（结构性标记，照旧用）**：

| 形态 | 用途 | 例 |
|---|---|---|
| `——※` | 接注记 | `她反而更不敢——※她怕开口会破坏那个状态。` |
| `——见《…》` | 交叉引用 | `——见《关系·依存度阶梯》60–80 段。` |
| `**小节名** ——` | 列表/字段引导 | `**③ 技术细节** —— 具体怎么做，含身体限制。` |
| `——第N章` | 章标前缀 | 章标正则在 `regex/02-正文容器美化.json` 里就是按 `(?:——)?` 写的，**这是契约**，别删 |

> 判断口径一句话：**它在标记结构，还是在替逗号干活？**
> 标记结构 → 留；替逗号干活 → 改。

### 5. 省略号、感叹号、波浪号只在承载真实停顿时使用

`……` `！` `～` 不许无功能堆砌。
标点是**停顿的记号**，不是情绪的装饰。没有真实停顿就不写。

## 自查（写完必须逐条跑，贴出数字）

```bash
# 指向你的世界书正文（.wb 文件目录）
WB=<世界书目录>

echo "1 对偶句:"; grep -roE "不是[^。！？\n]{1,20}(而是|，是)|并非[^。！？\n]{1,20}而是|与其说" "$WB" | wc -l
echo "2 八股连接词:"; grep -roE "首先|其次|由此可见|与此同时|然而|因此|综上" "$WB" | wc -l
echo "3 翻译腔:"; grep -roE "老实说|不得不承认|轻轻地|缓缓地|不由自主地" "$WB" | wc -l
echo "5 堆砌标点:"; grep -roE "…{2,}|！{2,}|～|~" "$WB" | wc -l

# 4 破折号：先扣掉结构性标记，只数「替逗号干活」的
echo -n "4 破折号(总): "; grep -ro "——" "$WB" | wc -l
echo -n "  其中结构标记(——※ / ——见《 / **xx** ——): "
grep -roE "——※|——\s*见《|——\s*第[一二三四五六七八九十百]+章|\*\*\s*——" "$WB" | wc -l
echo "  两个数相减 = 真违规"
```

**第 1、2、3 项必须为 0。** 第 4 项**减去结构标记后**必须为 0。
第 5 项按真实停顿判断，不是一律清零 ——
但 `！！！` `……` `～` 这类装饰性用法必须为 0。

> 注意：`！` 出现在**角色真实喊叫**的引号内是合法的；
> 出现在旁白里做强调就是堆砌。

> **示范句要格外盯**：世界书里那些全角空格缩进的例句（教 AI 语感的那些），
> 本身就是**被模仿的模板**。里面有一个破折号，等于亲手教 AI 违规。
> 查法（已排除章标 `——第N章`）：`grep -rnE "^　.*——" "$WB" | grep -vE "——\s*第[一二三四五六七八九十百]+章"`
> —— **必须为 0。**

### 实测基线（2026-09-21）

用上面这套命令跑一份约 81 个条目的世界书目录：

| 项 | 实测 | 判定 |
|---|---|---|
| 对偶句 | **1** | ❌ 人物条目「不是为学生，是为…」 |
| 八股连接词 | 5 → **2 真** | ❌ 两个条目分别命中「因此」「然而」；另 3 处「在其次」是"次要"义，**误报** |
| 翻译腔 | **0** | ✅ |
| 破折号 | 558 总 → **282 真** | ❌ 见下 |
| ↳ 结构标记 | 276 | ✅ `——※`163 / `**xx** ——`106 / `——见《》`6 / `——第N章`1 |
| ↳ **示范句里的** | **3** | ❌ 三条**文风规范类**条目的示范句里各有一处，**优先修这 3 处** |
| 堆砌标点 | 36 | ⚠️ 多为引号内真实停顿，需人工过 |

**结论**：这份世界书没有大面积违规，是一批需要手工清的零星处。
最该先动的是**文风规范类**条目 —— 它自己就是发给 AI 的规矩，
里面有 2 处「然而/因此」和 3 处示范句破折号，**属于"自己破自己的例"**。

> 条目名与文件名已隐去：它们是某一张具体卡内部的组织方式，对读者没有可迁移信息，
> 有价值的是**数字与那三条教训**。

## 九、内容组织（2026-09-30 新增）

前面八节管**句法**。这一节管**一条该写什么**。来源：用户提供的世界书写作指导。

### 9.1 一个条目 = 一个完整主题

一个"完整主题"可以是一处驿站、一个人物、一门剑术、一条商路、
一段家族史、一场当地事件。**条目内部要保留该主题成立所需的因果、语境、质感。**
篇幅由内容决定，不由配额决定。

| 条目类型 | 自己写充分 | 邻近资料各自成篇 |
|---|---|---|
| 城市 | 地理、规模、城区、生计、治理、交通、文化、局势 | 场所与人物给简短定位；详细档由各自关键词召回 |
| 酒馆 | 布局、食物酒水、客群、主人日常、价钱、营业节律、消息来源 | 老板的完整经历、当地阴谋另立条目 |
| 人物 | 身世、工作、动机、习惯、语言、资源、认知、日程、关系行为 | 能力列简明名称与常用表现；复杂机制另立条目 |
| 能力 | 效果、表现、使用方式、条件、代价、熟练变化、招式 | 持有者的完整传记由人物条目承载 |
| 事件 | 当事者、起因、现状、各方行动、线索、时间条件、后果 | 地区全史与总叙事规则留在已有资料 |
| 传闻 | 传播者、时间、说法、依据、偏见、可追问的人与地方 | 真相与深入调查在相应事件资料展开 |

**不要**在正文里解释条目之间怎么分工 —— 那是作者侧的事。

### 9.2 正向事实写作：边界要变成具体事实

这是本页 §1–§5 之外的**第五条硬规矩**，和禁句式同级。

**用户已明确禁止**把世界书正文写成防御性说明、免责声明或开发文档。
条目里**不出现**这些边界管理句：

```text
本条只负责…… / 不自动…… / 不等于…… / 不代表…… / 不得据此…… / 模型应避免……
```

**世界有边界，就写边界的实体承担者**：

| ✗ 管理句 | ✓ 具体事实 |
|---|---|
| 进入城镇不自动接任务、不增加好感 | 写城门、城区、来往者、服务、可交谈的人 |
| 拿到戒指不等于恋人，不代表血契 | 「血蔷薇戒指是家族使者的信物，背面刻有寄赠者的私印。成对持有者可在暮钟时传递一次短讯。」 |
| 本条只负责港口，不管理主线 | 写泊位、潮汐、船期、票价、搬运工、航路 |
| 未获许可不得进入，不自动识别身份 | 「西门夜间由家族卫士值守，持通行函的访客在门房登记，由引路人带往客馆。」 |
| 传闻不确认真相 | 「马夫前夜亲眼看见第七盏灯。他认得巡逻队的六盏提灯，对旧关内室的情况所知来自一名伤兵的转述。」 |
| 如果副模型漏写就恢复变量 | 在**运行时代码或变量设计**里解决；正文只留世界事实 |

> **注意**：仅把警告改成拗口肯定句，仍是工程说明。
> **正向表达必须增加实质信息** —— 换了个说法但没多告诉读者任何事，等于没改。

### 9.3 正文与作者工作分开

| 属于**正文** | 属于**作者侧** |
|---|---|
| 什么存在、如何运作、人们如何生活、何种条件带来何种结果 | 关键词、position、order、字段类型 |
| 名称、经历、地形、气候、服务、声音、法术效果、事件经过 | 变量路径、UI 消费者、脚本、桥接、调试、构建计划 |

**完成每条之后，删掉与该世界主题无关的管理段落。**

### 9.4 地点成稿示例（照这个密度写）

> 白鹿驿坐落在晨风城北面的旧军道旁，西侧马厩背靠一片桦树林，东侧石井接着从灰石山流下的浅溪。通往旧关的小路从驿站后坡分出去，载重马车通常在这里卸货，由骡队接运山路一程。
>
> 主楼底层是食堂与公共炉厅，二楼有六间客房，阁楼铺着供短住旅人使用的草垫。傍晚的厨房供应大麦汤、炖萝卜和黑面包；巡逻兵偏爱加盐的肉干，向导会在出发前灌满热水。老板把当天路况记在门旁的木板上，雪季每天清晨重新看一遍山顶云色。
>
> 马夫埃蒙熟悉旧军道的桥梁和沿路水源。商队抵达后，他先检查牲口蹄铁，再与赶车人交换路况。前夜旧关亮起了七盏灯，他记得巡逻队出发时带着六盏，因此向晨风驻军送了一封信。今晚来吃饭的士兵正等待回函。

**这条给的是**：空间、生计、感官、人物定位、现状。
**同时留了口子**：埃蒙的深入经历、旧关布局、搜救事件，各自另立条目。
**关键词**：`白鹿驿` `白鹿驿站`（专名 + 别名；配置在作者侧，不写进正文）。

### 9.5 势力与事件怎么写

- **势力**：领地、组织、资源来源、目标、内部派系、近期计划、调动能力、依赖。
  行动依据资源、信息、时令、他方反应发展。
- **事件**：是**正在发生的世界局面**，不是背景介绍。当事人各有目的，
  行动留下痕迹，玩家经询问、到访、阅读、跟踪、交易、合作介入。
  分别写清**客观情况 / 传播渠道 / 人物视角 / 证据**。
  某人撒谎时，写他相信什么、想隐瞒什么、说了什么、何时可能改口。
- **阶段资料**：描述局势与人物行动，选择和世界变化决定后续。
  叙事工具、状态提取、按钮命令在**作者侧**定义。

### 9.6 丰富度与上下文

**先把承诺的世界写充分，再安排按需召回。**

字数与总量依据主题和规模决定。库变大时，优先：精确关键词 → 拆分不同主题 →
调整窗口 → 消除重复。**不要**用"反正是按需召回"当借口把内容写薄。

### 9.7 作者侧完成检查（每条都过）

1. 正文每段都在增加该主题的世界知识。
2. 事实足够支撑场景，相关人、地点、事都有合理位置。
3. 关键词由**真实专名、别名、动作加具体对象、或已有标记**组成。
4. 邻近主题各有资料，必要的同时召回在配置里安排（RP-Hub 无递归，见 `keyword-design.md` §五）。
5. 工程词、免责声明、否定边界、开发历史**已移出正文**。
6. 既有总纲、玩家档案、作品事实、UI 在局部编辑中保持原样。
7. 同类条目的**小节顺序一致**（见 §9.8）；内容可以完全不同，格子必须一样。
8. 该条目引用的**下一阶段/下一步**已经写明（如有主线，见 `mainline-trigger.md` §四附）。
9. **keys 里有该条目的裸名**（`<标签>` 里的名字本身，v0.7.0）；长名另有别称的，别称也进 keys。
   跑 `node key-audit.mjs "<卡>" --list-bare`，清单必须为空。

### 9.8 六类条目的标准骨架（2026-10-04 新增）

> **来源与致谢**：本节的字段设计，提炼自 **娜娜米喵** 的综漫大世界卡《ArC 超越之影》，
> 以及一份实测 478 条目的大世界卡样本；同时吸收了酒馆预设侧的写作约束方法论。
> 感谢作者把这些结构做出来并愿意被学习。
>
> **本节只教骨架，不复制任何卡的文字内容。** 全部范例均为本 skill 原创，
> **不依赖、也不需要持有上述任何卡** —— 照骨架写自己的卡即可。

#### 为什么骨架比规则管用

社区里的世界书"每人一套写法"，通常不是因为作者不懂规则，
而是**每一次生成都没有正例可模仿**，只能各自发挥。

实测一份 276 个人物条目的大世界卡：**六大块的顺序在 98.3% 的条目里完全一致**。
统一靠的是**格子固定**，不是**文字相同**。
格式统一，内容自由 —— 这两件事不冲突。

> **判据**：一个条目的可信度，先看它的**小节顺序**是否与同类条目一致。
> 顺序乱 = 这份世界书没有标准，AI 每写一次都要重新猜。

> **骨架第一行的 `<标签>` 就是裸名，它必须原样进 keys（v0.7.0 铁律）。**
> 下面每个骨架都以 `<标签>` 开头（`<角色名>` / `<事件名>` / `<场所名>` …）。
> 那不是排版装饰：`gate.mjs` 的「裸名保底」项就是从这里读裸名，再检查 keys 里
> 有没有它的子串。只写 `地点：货运仓库` 这类前缀形式而漏掉 `货运仓库`，条目在
> 正文自然叙述下不触发。判据与病因见 `keyword-design.md` 第二附节。

#### 9.8.1 人物类 · 完整骨架

适合**主要人物**（会长期在场、有剧情权重）。

```text
<角色名>
【基础信息】
  姓名 / 性别 / 年龄 / 外貌 / 别名·身份 / 出身·所属 /
  等级或评级 / 能力 / 持有物 / 权限或权柄 / 战力 / 当前状态
【履历档案】
  第一人称自述生平，分段落。只写这个人自己会怎么讲自己的经历。
【声部一·社会互动】
  “这个人会说的台词”（什么场合说）
【声部二·内心独白】
  “这个人心里没说出口的话”
【声部三·他者视角】
  别人名：“对 ta 的评价”（什么场合）
【声部四·作者注解】
  核心魅力 / 最易误解 / 内核
  行为准则：表层性格·核心欲望·最大恐惧·性格弱点·底线·日常·
            面对亲近者·面对敌人·绝境时·说话方式·决策优先顺序
  写作红线：1. …（每条都必须跟一句正解）
  关键关系：关系名：关系定义 + 边界
【方向】            ← 角色随主线演化时写这里
  什么会推动她往哪动 / 什么会让她退回去
</角色名>
```

> **不写「【阶段N·时期名】」。** 那是把整条时间线塞进一条人物条目。
> 每个时期的她各写一份，等于人物条目替排期条目干了活，而且开局就剧透到底。
> 人物条目只给**方向**（什么推动她往哪动），进度归排期条目。
> 详见 `information-fog.md` §3。

**字段名用中性词**（`等级或评级` `能力` `持有物` `权限或权柄`），
换成任何题材都能用。别把某一部作品的专有名词写进骨架。

**四个字段是这份骨架的价值所在，别省**：

| 字段 | 它解决什么 | 少了会怎样 |
|---|---|---|
| 【声部一~三】对【声部四】 | 前三个给 AI **照着模仿的范例**，第四个给 AI **不许越界的约束** | 只有规则没有范例，AI 写出来的话不像这个人 |
| **最易误解** | 直接写「最容易写成什么样，但那是错的」 | 防崩坏停在抽象原则，AI 不知道具体警戒线 |
| **决策优先顺序** | 用 `＞` 排出一条偏序链，把价值判断变成可执行排序 | AI 遇到两难时按通用道德直觉处理，人物跑偏 |
| **关键关系带边界** | 不只说是什么关系，还说**不得**写成什么 | AI 把并肩写成情侣、把师徒写成父女 |

**范例 A · 完整版**（原创，现代都市题材 · 约 1100 字）

```text
<沈砚>
【基础信息】
姓名：沈砚。
性别：男。
年龄：三十四岁。
外貌：中等身高，常年穿深灰工装，袖口磨出浅白痕迹。右眼视力受损，戴单片镜，
镜片后的瞳孔颜色比左眼浅。左手食指第二节有旧疤。
别名·身份：旧城西街“衡记”钟表铺的老板；手艺行里叫他“听表的沈师傅”；
十年前在城南夜校兼过机械课。
出身·所属：本地人；不隶属任何行会，只在手艺行挂名。
等级或评级：手艺行三级匠师（自评二级，考级那年没去）。
能力：能听出机械的走时误差与磨损位置，误差在半秒以内可凭听觉定位；
拆装精贵机芯不留划痕。这项优势来自十七年的训练，不来自任何超常体质。
持有物：一套自己磨的游丝镊；父亲留下的怀表，表盖内刻着一个他不认识的名字；
“衡记”账簿。
权限或权柄：无。
战力：普通人。动手能力仅限工具使用。
当前状态：在业。

【履历档案】
我叫沈砚，在旧城西街开了十一年店。父亲也是修表的，铺子是他留下的。
我十七岁跟他学，二十五岁那年他把铺子交给我，自己去了外地，之后再没消息。

夜校教过三年机械课。有个学生总在课后留下来问问题，问得比课上细。
后来他出了事，学校换了门锁，我也没再去。

右眼是二十六岁在铺子里坏的，飞出来的发条片。医生说再晚一点就没了。
现在看细零件得戴镜。

【声部一·社会互动】
“表不走了不一定是坏。可能是你太久没上弦。”（客人抱怨走时）
“这块我修不了。零件没了，我不用替代件。”（拒单）
“你先坐。水在炉子上，自己倒。”（学徒进门）

【声部二·内心独白】
“父亲那枚表走得比新的还准。他走的时候没带走它。”
“我听得出来哪里不对。说出来也没用，客人要的是它能走。”

【声部三·他者视角】
面馆老板：“沈师傅话少，可他记得住每个客人的表。”（巷口闲聊）
旧城巡警：“那家铺子干净。真有事他也不吭声。”（巡逻记录）
夜校学生：“他讲齿轮的时候眼睛是亮的。”（毕业留言）

【声部四·作者注解】
核心魅力：一个把全部表达都放进手艺里的人。他对机械的耐心和对人的距离，
是同一个东西的两面。
最易误解：最容易把他写成沉默寡言的世外高人，或者被一段往事压垮的悲剧角色。
他过得很好，铺子有客，日子有准头。他话少是几十年的习惯。
他也从没想过要离开这条街。
内核：精确与克制。他相信能被校准的东西，也相信不能被校准的东西不该硬校。
行为准则：
- 表层性格：客气、话少、不主动搭话也不赶人。对熟客会多问一句。
- 核心欲望：把“衡记”开到关门那天，账目干净，手艺不传错人。
- 最大恐惧：手上的活儿开始抖，而他察觉不到。
- 性格弱点：拿手艺当衡量人的尺子。看不上不用心的人，也不掩饰。
- 底线：不骗客、不用替代件、不接来路不明的东西。
- 日常：早上六点半开门，先给铺里的钟上弦，再吃面。下午听广播，晚上记账。
- 面对亲近者：用活儿代替话。谁的表坏了他先修，修完才问最近怎么样。
- 面对敌人：退到柜台后面，不吵。真被逼急了会报警，也只会报警。
- 绝境时：先把客人的表收进柜子锁好，再处理自己的事。
- 说话方式：短句，先说结论。谈到机械会连着说好几句。
- 决策优先顺序：客人的表＞铺子的名声＞自己的安全＞父亲那枚怀表的去向
写作红线：
1. 他没有超常能力。听觉优势有明确来源，也有明确边界，写清楚它是练出来的。
2. 不写他主动离开旧城。他的所有选择都在这一条街的范围内发生。
3. 他对夜校那件事的沉默，正文只写事实，不写成赎罪。
关键关系：
学徒小满：带了三年的学徒，手稳但心不静。他会留下她，不替她做决定。不得写成父女。
旧城巡警老周：十年交情，每周来店一次，坐下不说话。可以托付小事，
不得写成线人或靠山。
父亲：已失联九年。铺子里不提他，怀表一直放在抽屉里。不得写成寻亲动机。
【阶段一·夜校时期】
剧情范围：他二十五岁到二十八岁，在夜校兼课，铺子刚接手。
年龄：二十五至二十八岁。
状态：话比现在多，愿意跟学生争论。右眼完好。
</沈砚>
```

#### 9.8.2 人物类 · 精简骨架

适合**次要人物**（只在特定场景出场）。**砍字段，不砍顺序。**

```text
<角色名>
【基础信息】
  姓名 / 性别 / 年龄 / 身份 / 外貌 / 能力 / 当前状态
【声部一·社会互动】
  “台词”（场合）
【声部三·他者视角】
  别人名：“评价”
【声部四·作者注解】
  核心魅力 / 最易误解
  行为准则：只留 2–3 条最关键的
  关键关系：只留会影响到剧情的那几条
</角色名>
```

**砍掉的**：【履历档案】【声部二·内心独白】、`决策优先顺序`、`阶段N`。
**保留的**：`最易误解` 和 `关键关系` 的边界，这两个是防崩坏的底线，次要人物也会崩。

**范例 B · 精简版**（原创 · 约 260 字）

```text
<周迟>
【基础信息】
姓名：周迟。性别：男。年龄：四十一岁。
身份：旧城巡警，负责西街一带。
外貌：个子高，警服总是扣到最上一颗。左边眉骨有一道旧疤。
能力：无超常能力。认得西街每一户的门牌和每一家店的关门时间。
当前状态：在业。

【声部一·社会互动】
“沈师傅，今天有热水吗。”（每周固定来店）
“这条街的事我大多知道。知道和能管是两回事。”（被问起纠纷）

【声部三·他者视角】
沈砚：“他来了就坐着，不点东西。”
面馆老板：“老周巡逻走到这儿，一般正好饭点。”

【声部四·作者注解】
核心魅力：一个把辖区当成自己责任范围的人。能力有限，但从不装作没有。
最易误解：最容易把他写成无能的官僚，或者热心过度、什么都管的邻里大叔。
他只管他能管的；管不了的，他记下来。
行为准则：
- 对外的耐心来自职业要求，他其实不耐烦。
- 遇事先记录，再按流程走。不走流程的事他不做。
关键关系：
沈砚：十年交情，每周固定来访。不得写成线人。
</周迟>
```

#### 9.8.3 事件类 · 标准骨架

事件条目写的是**正在发生的世界局面**，不是背景介绍（§9.5）。

```text
<事件名>

现在到哪一步了：（这个局面已经走到哪一步，一句事实说清）
地点：（多个用、分隔）
人物：（全部相关角色名，用、分隔）

事件：

事件1｜日期｜事件标题
（一段完整叙述：谁做了什么、留下什么痕迹）

事件2｜日期｜事件标题
（同上）

线索：

线索：

1. …（可核对的证据）
2. …

现状：

（此刻各方在做什么，玩家可以从哪里介入）

</事件名>
```

**「线索」是给 AI 的取证地图**，「现状」是给玩家的介入点。
两者都不写"真相是什么"，只写**能被查到的东西**。

**范例 C · 完整版**（原创 · 约 480 字）

```text
<西街停水>

时间：第七日清晨至第九日夜间
地点：旧城西街、北街公共水房、邻街泵房
人物：沈砚、周迟、面馆老板、西街住户、检修队

事件：

事件1｜第七日清晨｜通知上的三天工期
供水处在西街每个路口贴了通知，写明管网检修，工期三天。住户去北街公共水房取水，
水房限时开放两小时。第一天排队的人从门口排到巷尾。

事件2｜第八日｜检修队没有出现
检修队全天没有在西街出现。住户开始把水桶摆在自家门口，谁先接满谁挪开。
面馆老板把备用的大桶搬到了后厨。

事件3｜第九日中午｜面馆关门半天
店里的水压低到煮不了面。周迟当天记录了三次来访，供水处的答复都是“等通知”。
第九日夜里，住户自己排了取水顺序，按门牌单双日轮流。

线索：

1. 供水处的通知单在第七日以后没有再更新，落款日期与张贴日期不符。
2. 检修队在邻街出现过一次，带走一台泵，没有留下任何记录。
3. 北街水房的开放时间在第二日缩短了一小时，公告栏没有相应的通知。
4. 周迟的巡逻记录里，三次来访的接待人签名是同一个人的笔迹。

现状：

西街的住户已经按门牌轮流取水，秩序靠邻里自己维持。面馆老板准备改做冷食。
沈砚把铺子里的水壶全灌满，放在门口让过路的人自己倒。
玩家可以跟着周迟去供水处问一次，也可以去邻街找那台被带走的泵。

</西街停水>
```

#### 9.8.4 其余四类 · 短例

各给一段**照着写就不会散**的短例。骨架沿用 §9.1 的字段清单，这里只示范顺序。

**城市 / 地点**（骨架与密度见 §9.4，此处不重复）

```text
<城市名>
  地理与规模 → 城区与交通 → 生计与物产 → 治理与秩序 → 文化与人情 → 当前局势
</城市名>
```

**酒馆 / 场所**

```text
<青瓦巷口茶摊>
  位置与格局 / 供应什么 / 价钱 / 常客是谁 / 主人日常 / 营业节律 / 消息从哪来

青瓦巷口茶摊摆在巷子东头的老槐树下，三张矮桌围着树根摆开，雨天撑起油布棚。
只卖粗茶与炒货，一碗两文，续水不要钱。常客是巷里的搬运工与放学的小孩，

她每天听来的话比卖出的茶多，谁家办丧事、哪条路在修，她比巡警清楚。
</青瓦巷口茶摊>
```

**能力 / 技艺**

```text
<能力名>
  效果 / 表现（外人看到什么） / 发动方式与动作 / 条件与代价 / 训练如何改变它 / 明确的边界

<听时>
  沈砚能凭听觉判断机械的走时误差与磨损位置。
  外人看到的是他侧头听一会儿，然后直接指出该换哪个零件。
  他需要机芯在运转、环境足够安静，误差在半秒以内才分辨得出。
  连续听两小时以后，耳朵会闷半天。他右眼受损后，左耳负担更重。
  练习只能缩短判断时间，不能让他听见停摆的表。

```

**传闻**

```text
<传闻名>
  谁在传 / 什么时候开始传 / 说法是什么 / 依据是什么 / 传的人有什么偏见 /

<西街的水>
  巷口的人说西街停水是因为上游的水源出了问题，传了三天。
```

#### 9.8.5 常驻层怎么分组

常驻条目（`constant`）**不能平铺**，要按职责分组。
组名写进 `comment` 前缀，作者和 AI 一眼能看出这条管什么：

| 组 | 管什么 | 例 |
|---|---|---|
| **世界·** | 世界事实：地理、制度、经济、生态、权力结构 | `世界·六区环城与交通生活` |
| **规则·** | 硬约束：知识权限、判定规则、能力边界 | `规则·知识权限与调查证据` |
| **叙事·** | 文风与叙事气质、人物自主、关系表现 | `叙事·场景展开与慢节奏` |
| **运行·** | 输出格式、状态契约、标记约定 | `运行·最终输出格式` |
| **索引·** | 总目录：人物、作品、地点的一句话清单 | `索引·作品与人物总目录` |

**注入位置**：常驻规则放 `position: system_top`（最前，最稳）。
顺序由 `order` 控制，世界事实靠前，输出格式靠后。

> **规模警告（必须看）**：实测一份大世界卡用 **28 条常驻、合计约 4.2 万字**，
> 它总上下文在百万级，负担得起。**小卡照抄会直接爆预算。**
> 小卡的常驻层应当压到 **3–6 条、合计千字量级**：一条世界事实、一条规则、
> 一条输出契约，再加一条人物索引。**索引条目用一句话一人，不要写人物总览。**

#### 9.8.6 写作红线放在哪（与 §9.2 的边界）

§9.2 禁止把正文写成防御性说明。**声部四·作者注解是这条禁令的唯一例外**：
它是给 AI 的指令，被明确标记框起来了，与散落的世界描述不属同一类文本。

三条约束，缺一条就退化回 §9.2 要禁的东西：

1. **必须在标记块内**（`【声部四·作者注解】`），不能散落在世界描述里。
2. **只写"怎么演这个人"，不写"这份世界书怎么组装"**。
   写「不得写成父女」合法；写「本条只负责人物，不管理主线」违规。
3. **每条禁令后面必须跟正解**。只写禁止不写正解，AI 会换一种错法替代。
